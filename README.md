# Digital Footprint Analyzer

A Python web application that analyzes your digital footprint across various online platforms.

## Features
- Search username across 300+ platforms
- Generate detailed HTML and text reports
- Web interface via Flask
- Progressive Web App (PWA) support

## Installation

### Requirements
- Python 3.8+

### Setup
\\\
pip install -r web/requirements.txt
\\\

### Run Locally
\\\
python web/app.py
\\\

Open your browser at: http://localhost:5000

## Deployment
This app is deployed on Render.

## Tech Stack
- Python / Flask (Backend)
- HTML / CSS / JavaScript (Frontend)
- PWA support
